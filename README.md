# nationRPextension

Expansion mod for Unciv. Adds nations, city-states, unique units and unique buildings ported from Leader Mission 2 / Rising Power, adapted to **Civ V - Gods & Kings**.

Target: Unciv 5.0.1.4 and UncivCN.

## Not included

- Base ruleset content (techs, policies, beliefs, resources, terrains)
- Civilized Leader / Pope buildings
- Music
- Nation `personality` lines
- Diplomatic Point bonuses
- Per-city-state CityStateTypes (city-states use a shared template)

## Validate

In Unciv: Options → Locate mod errors, with base ruleset **Civ V - Gods & Kings**.

See [PORT_NOTES.md](PORT_NOTES.md) for dropped uniques and type mappings.

Icons are not in this first commit.
